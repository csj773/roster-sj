Slack Roster 앱 User Guide

Slack에서 roster를 가져오고, 공유 layover를 조회하고, 월간 PerDiem report를 실행하는 방법입니다.

기본 명령어

/roster-share
/roster-update
/roster-calendar
/my-roster
/layover
/perdiem-report
/roster-help

처음 사용하는 경우

먼저 본인의 Slack user와 Firebase roster user를 연결합니다.

/roster-share link-me

도움말은 언제든지 아래 명령으로 확인할 수 있습니다.

/roster-help
/roster-share help

Roster 가져오기

개인 iCal roster link를 Slack에서 import합니다.

/roster-share import webcal://your-private-calendar-url
/roster-update webcal://your-private-calendar-url

다른 사용자의 email owner로 import하려면 email을 같이 입력합니다.

/roster-share import friend@example.com webcal://your-private-calendar-url
/roster-update friend@example.com webcal://your-private-calendar-url

import, sync, link, ical, webcal은 같은 import action으로 처리됩니다.

내 Roster 조회

/my-roster
/my-roster HNL
/my-roster HNL 2026-07-22 14

마지막 예시는 2026-07-22부터 14일 동안 HNL이 포함된 본인 roster를 조회합니다.

공유 Layover 조회

/layover HNL
/layover HNL 2026-07-22 14

/layover는 본인 roster, 공유받은 roster, 같은 Slack team에 등록된 owner들의 roster를 함께 조회합니다.

검색은 roster collection을 먼저 사용하고, 해당 owner의 roster rows가 없을 때만 pdc/{uid}/events로 fallback합니다.

Calendar 형식 조회

/roster-calendar
/roster-calendar 2026-08
/roster-calendar HNL 2026-08

표시 순서는 08/03 choi sang joon YP152 HNL-ICN RO 23:10 Crew 보기 형식입니다.

Crew 보기를 누르면 해당 activity의 crew 명단을 볼 수 있습니다.

Roster Share 초대

/roster-share
/roster-share friend@example.com

초대를 받은 사용자가 수락하면 roster_shares에 공유 관계가 저장됩니다.

PerDiem Report

/perdiem-report
/perdiem-report user@example.com jul
/perdiem-report set-email user@example.com
/perdiem-report jul
/perdiem-report 2026-07

/perdiem-report는 Perdiem/{uid}/events data를 기준으로 계산합니다.

email을 지정한 report는 Firestore pdc 또는 users에서 owner를 찾습니다. slack_team_roster_owners는 PerDiem report 대상자를 정할 때 직접 사용되지 않습니다.

문제가 있을 때

  • Slack user가 연결되어 있지 않으면 /roster-share link-me를 먼저 실행합니다.
  • Roster import 후 layover에 보이지 않으면 import 성공 여부, Slack team, owner data, 조회 날짜 범위를 확인합니다.
  • PerDiem report owner를 못 찾으면 /perdiem-report user@example.com jul처럼 email을 지정합니다.

개인정보 주의

iCal roster link는 개인 roster 전체에 접근할 수 있는 private URL입니다. 가능하면 개인 DM이나 제한된 private channel에서 import 명령을 실행하세요. 앱은 원본 calendar URL을 Firestore에 저장하지 않습니다.
