# Pilotlog 개인정보처리방침

시행일: 2026년 7월 18일

Pilotlog 서비스(이하 "서비스")는 이용자의 개인정보를 중요하게 생각하며, 개인정보 보호법 등 관련 법령에 따라 개인정보를 안전하게 처리하기 위해 본 개인정보처리방침을 공개합니다.

본 문서는 배포 전 운영자 정보, 연락처, 실제 사용하는 외부 서비스와 보유기간을 최종 확인한 뒤 게시해야 합니다.

## 1. 개인정보의 처리 목적

서비스는 다음 목적을 위해 개인정보를 처리합니다.

| 처리 목적 | 내용 |
| --- | --- |
| 회원 식별 및 로그인 | Firebase Authentication을 통한 이용자 식별, 계정 관리 |
| 비행 기록 관리 | Pilotlog, roster, flight log, block time, night time, landing/takeoff 등 비행 기록 저장 및 조회 |
| 수당 및 리포트 관리 | PerDiem, Salary, transport fee 등 개인별 계산 결과 저장 및 리포트 생성 |
| 외부 연동 기능 제공 | Google Sheets, Google Calendar, GitHub Actions, Render API를 통한 동기화 및 자동화 |
| 보안 및 장애 대응 | 비정상 접근 탐지, 오류 분석, 로그 확인, 서비스 안정성 개선 |

## 2. 처리하는 개인정보 항목

서비스는 기능 제공에 필요한 최소한의 항목을 처리합니다.

| 구분 | 처리 항목 |
| --- | --- |
| 계정 정보 | Firebase Auth UID, 이메일 주소 |
| 비행 및 일정 정보 | 날짜, 편명, 출발지, 도착지, 항공기 등록번호, 비행시간, 야간시간, 이륙/착륙 횟수, crew/remark 등 이용자가 입력하거나 연동한 비행 관련 정보 |
| 정산 정보 | PerDiem, salary, transport fee, rate, month, year 등 계산 결과 |
| 자동화 실행 정보 | 동기화 실행 시간, 처리 결과, 오류 로그 |
| 보안 정보 | 접속 IP, 요청 헤더 일부, 인증 토큰 검증 결과, API 호출 로그 |

PDC 또는 CrewConnex 계정의 ID와 비밀번호는 자동 로그인 실행을 위해 전송될 수 있으나, 원칙적으로 Firestore에 저장하지 않습니다. 비밀번호는 실행 중 일시적으로만 사용해야 하며 로그에 노출되지 않도록 마스킹합니다.

## 3. 개인정보의 처리 및 보유기간

서비스는 목적 달성에 필요한 기간 동안 개인정보를 보유합니다.

| 개인정보 유형 | 보유기간 |
| --- | --- |
| 회원 계정 정보 | 회원 탈퇴 또는 삭제 요청 시까지 |
| 비행 기록 및 정산 기록 | 이용자가 삭제하거나 계정 삭제를 요청할 때까지 |
| 자동화 로그 | 장애 대응 및 감사 목적상 필요한 기간. 기본 90일 이내 보관 권장 |
| 백업 데이터 | 백업 정책에 따라 최대 30일 이내 보관 권장 |

법령상 보존 의무가 있거나 분쟁 대응을 위해 필요한 경우에는 해당 기간 동안 보관할 수 있습니다.

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 원칙적으로 제3자에게 제공하지 않습니다. 다만 다음의 경우에는 예외적으로 제공될 수 있습니다.

- 이용자가 사전에 동의한 경우
- 법령에 따라 제출 의무가 있는 경우
- 이용자의 생명, 신체, 재산 보호를 위해 긴급히 필요한 경우

## 5. 개인정보 처리업무의 위탁 및 외부 서비스 이용

서비스 운영을 위해 다음 외부 서비스를 사용할 수 있습니다.

| 수탁자 또는 서비스 | 이용 목적 | 처리되는 정보 |
| --- | --- | --- |
| Google Firebase | 인증, Firestore 데이터 저장, App Check | UID, 이메일, 서비스 데이터, 보안 로그 |
| Google Sheets | 비행 기록, 수당, 리포트 저장 | 비행 기록, 정산 결과 |
| Google Calendar | roster 일정 등록 | 날짜, 시간, 편명, 출발지, 도착지 |
| Render | backend API 실행 | API 요청 정보, 일시적 로그인 실행 정보 |
| GitHub Actions | 예약 동기화 및 리포트 생성 | 자동화 실행 로그, 리포트 산출물 |
| Gmail 또는 SMTP 서비스 | 리포트 이메일 발송 | 수신 이메일, 첨부 리포트 |

외부 서비스의 개인정보 처리방침은 각 서비스 제공자의 정책을 따릅니다.

## 6. 국외 이전

Firebase, Google Sheets, Google Calendar, Render, GitHub Actions 등 외부 클라우드 서비스를 사용하는 경우 개인정보가 국외 리전에 저장 또는 처리될 수 있습니다.

| 이전받는 자 | 이전 국가 | 이전 항목 | 이전 목적 | 보유 및 이용기간 |
| --- | --- | --- | --- | --- |
| Google | 미국 등 Google 인프라 운영 국가 | 계정 정보, 비행 기록, 정산 정보 | 인증, 데이터 저장, 문서/캘린더 연동 | 서비스 이용기간 또는 삭제 요청 시까지 |
| Render | 미국 등 Render 인프라 운영 국가 | API 요청 정보, 자동화 실행 정보 | backend API 실행 | 로그 보관기간 내 |
| GitHub | 미국 등 GitHub 인프라 운영 국가 | 자동화 실행 로그, 리포트 산출물 | GitHub Actions 자동화 | artifact 및 log 보관기간 내 |

실제 배포 전 사용 중인 리전과 외부 서비스 설정을 확인하여 위 표를 최신화해야 합니다.

## 7. 개인정보의 파기 절차 및 방법

서비스는 보유기간이 종료되거나 처리 목적이 달성된 개인정보를 지체 없이 파기합니다.

- 전자적 파일: 복구가 어렵도록 삭제하거나 접근 권한을 제거합니다.
- Firestore 문서: 이용자 UID 기준으로 관련 문서를 삭제합니다.
- Google Sheets/Calendar 데이터: 이용자 요청 또는 계정 삭제 시 관련 행과 일정을 삭제합니다.
- 백업 및 로그: 정해진 보관기간 경과 후 삭제합니다.

## 8. 이용자와 법정대리인의 권리 및 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- 개인정보 열람 요청
- 개인정보 정정 요청
- 개인정보 삭제 요청
- 개인정보 처리정지 요청
- 동의 철회 및 계정 삭제 요청

요청은 앱 내 문의 기능 또는 개인정보 보호책임자 연락처로 접수할 수 있습니다. 서비스는 본인 확인 후 관련 법령에 따라 처리합니다.

## 9. 개인정보의 안전성 확보조치

서비스는 개인정보 보호를 위해 다음 조치를 적용합니다.

- Firebase Authentication 기반 사용자 인증
- Firestore Security Rules를 통한 사용자별 데이터 접근 제한
- Firebase App Check를 통한 비정상 클라이언트 접근 방지
- 서비스 계정 키와 API 키의 서버 측 보관
- Render 및 GitHub Secrets를 통한 비밀값 관리
- HTTPS 기반 통신
- 로그 내 비밀번호 및 민감정보 마스킹
- 최소 권한 원칙에 따른 Google Sheets/Calendar 공유
- 예산 알림과 사용량 모니터링을 통한 과도한 비용 발생 방지

## 10. 쿠키 및 유사 기술

서비스는 Firebase, FlutterFlow, Google 서비스의 인증 유지, 보안 확인, 서비스 품질 개선을 위해 쿠키 또는 유사 기술을 사용할 수 있습니다. 이용자는 브라우저 설정을 통해 쿠키 저장을 제한할 수 있으나, 이 경우 일부 기능이 제한될 수 있습니다.

## 11. 만 14세 미만 아동의 개인정보

서비스는 원칙적으로 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 아동의 개인정보가 수집된 사실을 알게 된 경우 지체 없이 삭제합니다.
